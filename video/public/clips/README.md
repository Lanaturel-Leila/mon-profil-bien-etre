# 📥 Déposer une vidéo ici

C'est dans ce dossier que vont les vidéos à monter.

## Depuis le téléphone ou le navigateur

1. En haut de cette page, le bouton **Add file** → **Upload files**
   (sur téléphone : les trois points **⋯** puis **Upload files**).
2. Choisis ta vidéo.
3. Tout en bas, bouton vert **Commit changes**.

Vérifie juste que le nom de la branche affiché en haut est bien
`claude/install-remotion-610qqu`.

## La taille

Par le navigateur, GitHub refuse les fichiers de plus de **25 Mo**.

Si ta vidéo est plus lourde :

- sur iPhone, ouvre-la dans Photos, **rogne-la** (les curseurs sous l'image) et
  enregistre l'extrait : ça allège beaucoup ;
- ou envoie d'abord un bout de la vidéo pour qu'on cale le montage ;
- ou dis-le simplement, et on trouvera un autre chemin.

## Ensuite

Les fichiers posés ici se listent dans `../../src/clips.ts` — c'est là qu'on
écrit les coupes. Voir le mode d'emploi dans `../../README.md`.
